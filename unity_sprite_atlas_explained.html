Unity Sprite Atlas 쉽게 이해하기

Sprite Atlas는 여러 개의 Sprite 이미지를 하나의 큰 Texture로 묶어서, Unity가 더 효율적으로 그릴 수 있게 해주는 2D/ UI 최적화 기능입니다.

🎮 2D 게임 🧩 UI 아이콘 📱 모바일 최적화 ⚡ Draw Call 감소

1. Sprite Atlas란?

Unity에서 Sprite는 UI 아이콘, 캐릭터 이미지, 타일, 이펙트 조각처럼 2D로 그려지는 이미지입니다. Sprite Atlas는 이런 Sprite들을 한 장의 큰 이미지판에 모아두는 기능입니다.

한 줄로 말하면: 여러 이미지를 한 장에 묶어서, GPU가 이미지를 덜 바꾸고 더 효율적으로 그리게 하는 기능입니다.

3. Atlas를 쓰면 왜 빨라질까?

❌ Atlas를 사용하지 않을 때

UI에 저장, 불러오기, 삭제, 별, 버튼 이미지가 각각 따로 있으면 Unity는 여러 Texture를 계속 바꿔가며 그려야 합니다.

save.png 사용 → 그리기 load.png 사용 → 그리기 delete.png 사용 → 그리기 star.png 사용 → 그리기 button.png 사용 → 그리기 결과: Texture 전환 증가, Draw Call 증가 가능

✅ Atlas를 사용할 때

여러 Sprite가 같은 Atlas Texture 안에 들어 있으면 Unity는 같은 Texture를 공유하면서 더 잘 묶어서 그릴 수 있습니다.

UI_Common_Atlas 사용 ├─ save 영역만 잘라서 사용 ├─ load 영역만 잘라서 사용 ├─ delete 영역만 잘라서 사용 ├─ star 영역만 잘라서 사용 └─ button 영역만 잘라서 사용 결과: Batching에 유리, Draw Call 감소 가능

Unity 공식 문서에서도 Sprite Atlas는 여러 Sprite Texture를 하나의 Atlas Texture로 패킹하는 유틸리티로 설명됩니다. Atlas 안의 Sprite들은 같은 큰 Texture의 일부 영역을 잘라 쓰는 방식으로 이해하면 됩니다.

4. Sprite Sheet와 Sprite Atlas의 차이

구분 Sprite Sheet Sprite Atlas
주 목적 애니메이션 프레임을 한 이미지에 모아 관리 여러 Sprite를 묶어서 렌더링 최적화
예시 캐릭터 걷기 1, 2, 3, 4 프레임 Save, Load, Delete, Ranking, History 아이콘
제작 방식 보통 이미지 한 장을 직접 만들고 Slice Unity가 여러 Sprite를 자동으로 Packing
초보자 기억법 애니메이션용 이미지 묶음 성능 최적화용 이미지 묶음

5. Unity에서 Sprite Atlas 만드는 흐름

🖼️Sprite 준비
아이콘, 버튼, 배지 PNG를 준비합니다.
📦Atlas 생성
Assets > Create > 2D > Sprite Atlas
➕Sprite 추가
Objects for Packing에 Sprite나 폴더를 넣습니다.
👀Pack Preview
어떻게 묶였는지 미리 확인합니다.
🎮게임에서 사용
기존 Sprite를 UI Image나 SpriteRenderer에서 그대로 사용합니다.
Atlas를 만들었다고 Sprite를 코드에서 특별히 다른 방식으로 불러야 하는 것은 아닙니다. 보통은 기존 Sprite를 그대로 사용하면 Unity가 빌드/실행 과정에서 Atlas를 연결해줍니다.

6. Inspector 주요 옵션 쉽게 보기

옵션 쉬운 설명 추천
Include in Build 이 Atlas를 빌드에 포함할지 정합니다. 일반 UI/2D Sprite는 켜기
Allow Rotation 공간을 아끼려고 Sprite를 회전해서 넣을 수 있게 합니다. UI용 Atlas는 끄기 권장
Tight Packing Sprite의 실제 모양에 맞춰 더 촘촘하게 넣습니다. 아이콘은 가능, 버튼/패널/9-Slice는 끄기 권장
Padding Sprite와 Sprite 사이의 여백입니다. 여백이 너무 작으면 옆 이미지 색이 번져 보일 수 있습니다. 보통 4 이상, 번짐 있으면 8
Read/Write 스크립트에서 Texture 픽셀을 읽거나 수정할 수 있게 합니다. 일반적으로 끄기
Filter Mode 이미지가 확대/축소될 때 보이는 방식을 정합니다. 픽셀아트는 Point, 일반 UI는 Bilinear
UI 이미지가 이상하게 회전되어 보이거나, 버튼/패널 테두리가 잘린다면 Allow Rotation과 Tight Packing을 먼저 꺼보는 것이 좋습니다.

7. UI 프로젝트에서 추천 Atlas 분리 방식

모든 이미지를 Atlas 하나에 전부 넣는 것보다, 같이 자주 쓰이는 이미지끼리 나누는 편이 관리하기 쉽습니다.

UI_ButtonIcons_Atlas

Save, Load, Delete, Select, Reset, Draw, Ranking, History 같은 버튼 아이콘

UI_Badges_Atlas

ALL, A, B, C, D 그룹 배지나 등급 아이콘

UI_NumberIcons_Atlas

0~9 숫자 아이콘, 점수 선택 UI에 쓰는 숫자 Sprite

Assets/ └─ Sprites/ ├─ UI/ │ ├─ Icons/ │ ├─ Buttons/ │ ├─ Badges/ │ └─ Numbers/ └─ Atlases/ ├─ UI_ButtonIcons_Atlas.spriteatlasv2 ├─ UI_Badges_Atlas.spriteatlasv2 └─ UI_NumberIcons_Atlas.spriteatlasv2

8. 초보자가 자주 하는 실수

⚠️같은 Sprite를 여러 Atlas에 넣음
어느 Atlas를 쓸지 관리가 꼬일 수 있습니다.
🧱하나의 Atlas에 전부 넣음
작은 UI 하나만 필요한데 큰 Atlas가 로드될 수 있습니다.
🔄UI용 Rotation 켜둠
UI Sprite가 회전되어 보이는 문제가 생길 수 있습니다.
📏Padding 너무 작음
인접 Sprite 색이 가장자리에 번져 보일 수 있습니다.

9. 최종 요약

  • Sprite Atlas = 여러 Sprite를 큰 Texture 한 장에 묶는 기능
  • 목적 = Draw Call 감소와 렌더링 최적화
  • UI용 Atlas = Allow Rotation 끄기 권장
  • Padding = 보통 4 이상
  • Read/Write = 특별한 이유 없으면 끄기
  • 같이 쓰는 이미지끼리 Atlas를 나누기
